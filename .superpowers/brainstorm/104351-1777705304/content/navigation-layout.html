Question 5 — Structure de navigation de l'app

Quel layout principal pour l'interface des membres ?

A — Sidebar fixe

Navigation latérale permanente. Idéale sur desktop. Menu icon-only sur mobile. Classique pour les dashboards administratifs.

B — Top nav

Barre horizontale en haut. Plus compact, familier sur mobile. Bien quand les sections principales sont peu nombreuses (4–5 max).

C — Bottom nav (mobile-first)

Barre en bas, style app mobile. Optimal sur téléphone — pouce accessible. Moins adapté sur desktop large.

Ma recommandation : A — Sidebar fixe. Les admins et le bureau vont beaucoup utiliser l'app sur desktop pour valider les paiements. Les membres accèdent depuis mobile, mais leurs actions sont rares (confirmer réception). La sidebar se réduit bien en icônes sur petit écran.
